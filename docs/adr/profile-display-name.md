# 档案显示名策略

## 决定

`profile_id` 是本机档案和成绩归属的唯一身份，显示名可以修改。排行榜与最近记录显示
`profiles.display_name` 的当前值；`attempts.player` 保留结算当时的名字，只在档案行缺失或
修复数据时作为后备值。

## 原因

同一位玩家改名后不应在排行榜中出现两份身份，也不应要求重写所有历史成绩。保留结算时
名字仍有助于恢复旧库，并能在档案数据损坏时提供可读的后备显示。

## 约束

- 显示名经过 NFC 规范化，去除首尾空白，最长 32 个字符，不接受控制字符；
- 旧版本把显示名当作身份时，使用固定命名空间的 UUIDv5 映射；
- 新档案使用随机 UUID；
- 删除档案不应顺带删除成绩历史。当前界面因此只提供新建、切换和改名，删除与合并要等到
  有可导出备份和明确确认流程后再开放。
